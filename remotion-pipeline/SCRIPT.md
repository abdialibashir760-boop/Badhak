# Short script — "Why the Leaning Tower of Pisa survived earthquakes" (~30s, ~4 words/sec)

1. It should have collapsed. Four earthquakes. It's still standing — still leaning. (hook)
2. Eight centuries of shaking, and the tower never fell. Engineers were baffled.
3. You see... the soft soil under it is what makes it tilt.
4. That same soft soil lets the tower sway, out of step with the quake's waves.
5. Scientists call it dynamic soil–structure interaction. The tower rides the shaking.
6. The flaw that bent it is the flaw that saved it. (ironic twist)
